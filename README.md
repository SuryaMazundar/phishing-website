# phishing-website

## 1. Create a Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 2. Install Dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## 5. Run the Application

```bash
python app.py
```
The application runs locally at:
**http://127.0.0.1:5000*
